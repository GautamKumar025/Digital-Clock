# ⏰ Digital Clock

A simple, clean, and real-time **Digital Clock** web application built using **HTML**, **CSS**, and **JavaScript**. It dynamically displays the current time (hours, minutes, and seconds) accurately on any screen size.

## ✨ Features
* **Real-Time Updates:** Automatically updates every second using JavaScript's `Date` object and `setInterval()`.
* **Clean & Modern UI:** Styled with CSS for easy readability and a sleek digital look.
* **Responsive Design:** Works smoothly on desktop, tablet, and mobile screens.
* **Zero Dependencies:** Built purely with vanilla web technologies—no external libraries required.

## 🛠️ Technologies Used
* **HTML5** – Structure of the clock display.
* **CSS3** – Styling, layout, and typography.
* **JavaScript (ES6)** – Live time calculation and DOM manipulation.
